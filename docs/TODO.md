## Серверная часть (согласовано)

Решения:
- Права касаются только зон на карте (видеть / править / управлять), защиты блоков нет.
- Платформы: Fabric (один jar для клиента и сервера) и Paper 1.21.11. Spigot не нужен.
- Локальные зоны остаются локальными: отдельный слой «Мои», на сервер не отправляются.
- Серверные зоны создают только админы и игроки с правом `exactselection.create` (роль в LuckPerms; у операторов есть всегда).
- Видимость выбирается при создании зоны: всем или выбранным игрокам и ролям.
- Уровни прав на зону: смотреть / править / управлять (управлять = раздавать права и удалять). Владелец и `exactselection.admin` могут всё.
- Права раздают владелец зоны (в окне «Доступ…»), админы (командами `/es`) и роли (LuckPerms: fabric-permissions-api на Fabric, встроенные права на Paper).

Устройство:
- Gradle-модули: `common` (геометрия, модель, проверка, протокол, права, хранилище — без Minecraft), `fabric`, `paper`.
- Канал `exact_selection:sync`, сообщения JSON с длиной. Полный снимок измерения по частям (пакеты сервера до 1 МБ, клиента ~32 КБ), затем операции: создать / изменить / удалить зону и группу, выдать права; ответы ok / отказ с причиной; версия протокола в приветствии.
- Сервер — главный: проверяет права, лимиты, геометрию и частоту запросов; хранит файл на измерение в папке мира; рассылает изменения только тем, кто может видеть зону.
- У зоны ревизия: правка устаревшей версии отклоняется («зона изменена другим игроком»).
- Клиент: вкладки «Мои» / «Сервер» в окне «Области», выбор видимости при сохранении на сервер, окно «Доступ…». Отмена для серверных зон — обратной операцией, а не заменой всего списка.
- Команды `/es`: список зон, удаление, выдача прав, смена владельца.
